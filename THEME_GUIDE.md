# Guia de Padronização Visual

## Recomendações de Cores
- Verde Exército: #4CAF50
- Cinza neutro: #F5F5F5
- Preto: #222

## Fontes sugeridas
- Roboto
- Arial
- Helvetica

## Dicas
- Use as cores e fontes sugeridas em todos os módulos para manter identidade visual.
- Adicione CSS customizado nos templates para unificar aparência.
